Blockend adds backend code to your project. You choose a block, and the CLI writes its source files into your repository. You can read and change that code like the rest of your app.

## Quick start

From your project folder, create a Blockend config and add a block:

```bash
pnpm dlx blockend-cli init
pnpm dlx blockend-cli add rate-limiter
```

The CLI asks how your project is set up, then places the block in the configured directory. Open the [initialization guide](/docs/01-getting-started/01-intialization) if you want to review or change those choices. Use the [add blocks guide](/docs/01-getting-started/02-adding-new-block) to choose another block or understand what the CLI writes.
