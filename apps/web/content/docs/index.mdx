Blockend copies backend source files into your project. You choose a block, and the CLI writes its code into your repository. You can read, edit, and commit it like the rest of your app.

## Quick start

From your project root:

```bash
pnpm dlx blockend-cli init
pnpm dlx blockend-cli add rate-limiter
```

`init` creates `blockend.json`. `add` writes the block files under the configured blocks directory.
