## Add a block

```bash
pnpm dlx blockend-cli add <block-key>
```

If you have not initialized the project yet:

```bash
pnpm dlx blockend-cli init
```

For variant selection, dependency prompts, and file conflicts, see [Add blocks](/docs/01-getting-started/02-adding-new-block).
